# Student Management System

A Java-based Student Management System using JDBC and MySQL that performs CRUD operations.

## Features
- Add Student
- View Students
- Update Student Details
- Delete Student Records
- MySQL Database Connectivity
- JDBC Implementation

## Technologies Used
- Java
- JDBC
- MySQL

## Project Structure
DBConnection.java
Main.java
Student.java
StudentDAO.java

## How to Run
1. Create a MySQL database.
2. Update database credentials in DBConnection.java.
3. Compile all Java files.
4. Run Main.java.
